# Home

Welcome to "An Introduction to Computing with Julia". This book collects the lecture notes for MAC0115 - Introduction to Computing for Exact Sciences and Technology. Written in simple, direct language, it presents the main concepts of programming, complemented by practical code examples.

This course introduces the foundations of computing through a historical journey that leads up to practical programming concepts using the Julia language. It covers algorithms, computer architecture, algorithmic languages (expressions, statements, data structures and functions), development methodologies and good programming practices, along with extensive programming and debugging practice.

The book is being updated alongside the course. The order and the examples may change, but nothing that affects the content taught. Don't worry if something isn't exactly where you expected to find it.
